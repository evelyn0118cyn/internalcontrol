## 八、遗留与建议

1. **评分公式扣分偏严**：严格按 Prompt 公式实现后，缺陷多、等级高时总分可能为负。若集团希望总分落在 0–100，
   建议后续调整缺陷扣分系数（设置区已开放「缺陷扣分系数」，默认 2，可调为 0.2 等）。当前实现不擅自改动 Prompt 口径。
2. **示例数据为演示材料**：内置 120 个控制点为演示数据（口径与 Prompt 示例一致），正式使用请导入集团真实材料。
3. **内部制度为占位条款**：未内嵌集团正式制度文本，请在「内部制度补充」粘贴真实条款后重新评估，结论引用会随之替换。
4. **PDF 依赖浏览器打印**：跨浏览器排版可能有细微差异，重要报告建议使用 Chrome / Edge 打印为 PDF。
5. **API Key 前端明文存储**：符合架构 I 的约束，但请使用权限最小化的密钥，并在公用电脑上避免保存。
