## v1.0 — 2026-11-18 11:27

### 新增（首个正式交付版本）
- **单文件交付物** `index.html`（约 2.2 MB）：内联 SheetJS 0.18.5 与 ECharts 5.5.1，双击即开、`file://` 离线可用，无外链、无 404、控制台无报错。
- **三步工作流**：① 导入材料 → ② 逐点评估 → ③ 出具结论，左侧步骤导航 + 中间工作区 + 右侧常驻结论速览卡。
- **材料导入**：Excel / CSV 上传、粘贴文本、表单填写三种方式；内置 120 个控制点演示材料一键载入。
- **逐点评估**：120 个控制点全部评估、不抽样不遗漏；双维度 checklist（设计 4 项 + 运行 3 项），逐项判定依据可追溯。
- **缺陷认定**：定量三级金额阈值（一般 < 100 万 / 重要 100–500 万 / 重大 ≥ 500 万，可调）+ 8 条定性红线，双标准取较高等级、定性优先。
- **根因合并**：按「根因标签 + 责任部门 + 流程」三维聚类，保留关联控制点编号与合并前数量。
- **加权评分**：风险矩阵法（可能性 × 影响程度），缺陷权重 一般 1 / 重要 3 / 重大 8（重大 ≥ 一般 5 倍），逐步展示公式代入过程。
- **结论判定**：任意 1 条重大缺陷即一票否决判「无效」；无重大缺陷时按总分分档（≥80 有效 / 60–79 基本有效 / <60 无效）。
- **红色预警**：存在重大缺陷时顶部红色横幅 + 预警卡（含缺陷描述 / 涉及控制点 / 法规依据 / 责任部门 / 整改建议 / 风险等级 6 项要素）。
- **四份成果导出**：控制点评估表、缺陷清单、评分明细、评价结论；支持 CSV / Excel / 打印或另存为 PDF / 一键打包 ZIP。
- **大模型语义增强**：服务商 Finance AI（跃客科技）、模型 `deepseek-flash`；只做判定依据一句话 / 缺陷根因摘要 / 结论措辞，任何等级判定与评分一律以规则引擎为准；API 设置面板可改服务商 / 模型 / Key / BaseURL，temperature 固定 0.1。
- **失败降级**：401 / 429 / 超时 / 网络或跨域错误时提示并切换为规则引擎结果，结论与评分不受影响；可关闭语义增强全程离线运行。
- **内嵌测试示例**：12 个控制点 + 固定预期输出，一键运行并将「预期输出」与「实际结果」并排比对（✅ / ❌），含可复现性检查。
- **操作日志与历史**：每次操作写入本地日志（可查看并下载 `useractivity.log`），每次评估保存一条结论摘要（历史评估记录）。
- **数据与隐私**：三份材料解析后仅保存在浏览器内存与 localStorage，不上传至除大模型 API 之外的任何服务器；提供「清空全部材料」一键删除本地缓存。
