架构I：纯前端项目 — 技术要求
================================

1. 定位与适用场景
---------------------------------
- 适用于无需外部数据源、无需持久化服务器、只需静态交互的轻量应用。
- 典型：工具类网页、演示原型、单页计算器 / 表单 / 可视化 / 静态报告展示。

2. 启动与运行方式
---------------------------------
- 交付物：单个 index.html。
- 启动：双击 index.html，浏览器直接打开并运行。
- 无需安装依赖、无需启动服务器、无需配置环境。

3. 技术要求
---------------------------------
- 所有 CSS / JS 必须内联于 index.html，或通过 HTTPS CDN 加载。
- 禁止以相对路径引用本地 .js / .css 文件（file:// 协议下部分浏览器会拦截）。
- 不依赖任何后端服务、数据库或本地运行时。
- 大模型能力（如需要）：由浏览器直接 fetch 第三方 API；
  API Key 存放于前端（localStorage 或页面输入），用户需知晓其安全风险。

4. 约束与边界
---------------------------------
- 受浏览器安全沙箱限制：不能直接读服务器文件、不能连数据库、不能监听端口。
- file:// 协议下浏览器禁止 fetch 本地文件，所有数据必须硬编码或内联。
- 跨域（CORS）限制：直连第三方 API 需该服务显式允许跨域。

5. 验收要点
---------------------------------
- 双击即开、离线可用。
- 浏览器控制台无报错、无外链 404。
- 可整体复制 / 分享，迁移目录后功能不丢失。
